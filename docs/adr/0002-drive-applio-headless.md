# Drive Applio's headless core.py instead of reimplementing RVC

Training and Conversion call Applio's `core.py` subcommands (preprocess, extract, train, index, infer) from a pinned commit, run as subprocesses. Voice Models then stay byte-compatible with the existing `my-voice_60e_6660s.pth` and with Colab-trained models, and a crash in a training step can't take the desktop window down with it. The cost is depending on Applio's CLI flags, which can change between commits. That's why the commit is pinned: `vendor/Applio` @ `59c113106c0dfff647324ab1a80c286f17b51929` (2026-10-28). Applio's own `requirements-engine.txt` pins CUDA torch and NVIDIA libraries, which would replace the ROCm build. `requirements-applio.txt` is the same list without them, with CPU `onnxruntime` and `demucs` added.
